Ce hub joue le rôle d'une page « ressources / documentation » dans une arborescence réelle : il complète le catalogue de vitrines sans les dupliquer. Utilisez les captures desktop, tablette et mobile pour repérer débordements, contrastes et respiration typographique.

Les chemins relatifs fonctionnent derrière un serveur statique ; les visuels sont des illustrations d'ambiance ; les ancres valident le scroll-margin et la navigation clavier sur les pages longues.
