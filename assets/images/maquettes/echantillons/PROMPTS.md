# Prompts maquettes `/echantillons`

Style commun (toutes les scenes) :

- UI site web marketing premium technique (pas cartoon, pas flat vide)
- Palette : fond clair `#f5f7fb` vers `#e9eef6`, encre `#0f172a`, bleu UI `#2563eb`, accents cyan `#7bcde3` / vert doux `#91b98a`
- **Accent CTA / rubans** : ambre `#d97706` / `#f59e0b` (complementaire du bleu, **pas de rouge**)
- Typo claire, textes en **francais**, marque **DanielCraft** discrete en header
- Atmosphere proche des pages `/bouquins` et `/nos-offres` (search hero + deal week + grille)
- **Pas de prix** sur les echantillons (ce ne sont pas a vendre) - CTAs « Voir la fiche » / « Demo live » / « Parler d'un projet »
