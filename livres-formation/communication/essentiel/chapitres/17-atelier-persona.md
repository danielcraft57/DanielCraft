# Atelier 1 - Persona message (a qui + quoi dire)

Cet atelier te fabrique une fiche simple : une personne type + le message qui lui parle. Duree visee : 35 a 45 minutes. Une feuille ou un doc suffit.

## Etape 1 - Choisis le contexte (5 min)

Note ton projet du moment. Exemples : "recruter 6 benevoles pour la collecte", "expliquer mon offre de site vitrine a des artisans", "annoncer le changement de cantine aux parents", "presenter mon atelier bois a des debutants".

Ecris aussi l'objectif en un mot : informer / convaincre / rassurer / federer.

## Etape 2 - Dessine la personne (10 min)

Donne-lui un prenom. Age approximatif. Situation (parent, client, benevole, collegue...). Ce qu'elle veut. Ce qu'elle craint. Ou elle lit ses infos (mail, WhatsApp, Instagram, affiche, reunion). Le niveau de jargon qu'elle supporte (bas / moyen).

Exemple : "Nadia, 38 ans, parent d'un CE2, lit les mails le soir, veut savoir si la sortie est obligatoire et combien ca coute, a peur des infos incompletes, jargon bas."

## Etape 3 - Phrase centrale (5 min)

Ecris la seule phrase que Nadia doit pouvoir repeter. Pas trois. Une. Exemple : "La sortie musee est facultative, cout 4 euros, autorisation a rendre vendredi."

## Etape 4 - Message complet (10 min)

Structure :

Idee principale.

Contexte en 2 phrases max.

Action claire (quoi faire, pour quand, ou).

Preuve ou detail utile (un seul).

Ton : tes trois mots d'identite.

## Etape 5 - Test eclair (5 a 10 min)

Montre le message a quelqu'un qui n'est pas dans le sujet. Demande : "C'est pour qui ? Qu'est-ce qu'il faut faire ?" Si la reponse est juste, valide. Si non, corrige la premiere phrase et l'action.

## Livrable

Une fiche "Persona message" avec : prenom type, objectif, phrase centrale, message complet, canal choisi. Range-la. Tu la reutiliseras pour l'atelier plan.

## Variante equipe

Si vous etes plusieurs, faites deux personas differents pour le meme evenement (ex: parents / enseignants). Comparez. Vous verrez vite pourquoi un seul texte unique coince souvent.

## Mini defi

Reecris un ancien message flou avec ta nouvelle fiche. Envoie-le (ou prepare-le). Garde les deux versions pour voir la difference.
