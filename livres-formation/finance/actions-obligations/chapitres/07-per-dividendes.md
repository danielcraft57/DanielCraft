# Chapitre 7 - PER et dividendes

Le **PER** (Price / Earnings) compare le prix de l'action au benefice par action. Le **dividende** montre ce qui est redistribue. Seuls, ils trompent. Ensemble, avec le **payout** et l'historique de benefice, ils aident a poser des questions honnetes. Chez DanielCraft, on refuse le slogan "PER bas = achete".

Ce chapitre est pedagogique. Les chiffres sont inventes.

## PER : formule et lecture

PER = Prix de l'action / Benefice par action (BPA)

Exemple :
- Prix = 40 EUR
- BPA = 4 EUR
- PER = 40 / 4 = 10

Un PER a 10 signifie : "au rythme actuel de benefice, le marche paie 10 annees de benefices". Ce n'est pas une prediction. Si le BPA s'effondre a 1 EUR l'an prochain, le PER "historique" devient trompeur.

PER forward (intuition) :

PER forward = Prix / BPA estime de l'an prochain

Si le marche est optimiste sur la croissance, le PER forward peut etre plus bas que le PER "trailing" (sur les 12 derniers mois). Inversement si les previsions baissent.

## Gordon / dividende : intuition de valorisation

Pour une entreprise qui verse un dividende croissant a un rythme constant (hypothese forte) :

V0 = D1 / (r - g)

avec :
- D1 = dividende attendu l'an prochain
- r = rendement exige par l'investisseur
- g = taux de croissance du dividende (g < r)

Exemple pedagogique :
- D1 = 2 EUR
- r = 8 % = 0,08
- g = 3 % = 0,03

V0 = 2 / (0,08 - 0,03) = 2 / 0,05 = 40 EUR

Si le cours cote 55 EUR alors que ton modele donne 40, tu n'achetes pas "parce que le marche a toujours raison". Tu demandes : mon r est-il trop bas ? mon g trop haut ? ou le marche est-il trop optimiste ?

Croissance soutenable (intuition) :

g ~ (1 - payout) x ROE

Si payout = 40 % et ROE = 12 %, alors g ~ 0,60 x 0,12 = 7,2 %. Au-dela, mefie-toi d'un g "reve" dans un pitch.

## Payout et rendement dividende

Payout = Dividende par action / BPA

Rendement dividende = Dividende / Prix

Exemple :
- Dividende = 2 EUR, BPA = 4 EUR, Prix = 50 EUR
- Payout = 50 %
- Rendement = 2 / 50 = 4 %

Si payout = 120 %, l'entreprise redistribue plus que son benefice : dette, cession d'actifs, ou situation temporaire. Max marque "orange" tant qu'il n'a pas compris comment c'est finance.

## Petite histoire

Sam compare deux actions :
- A : rendement dividende 8 %, payout 115 %, BPA en baisse 3 ans
- B : rendement 3 %, payout 45 %, BPA stable

Il choisit B pour sa poche long terme. Moins de spectacle. Plus de sommeil.

## Erreur classique

Acheter uniquement sur "gros dividende". Ou comparer des PER de secteurs trop differents (banque vs tech) sans contexte. Ou oublier la dette nette quand on lit seulement le BPA.

## En vrai

Sur une fiche : PER trailing, PER forward si dispo, rendement dividende, payout, evolution BPA 3 ans. Quatre lignes. Une decision ecrite.

## Mini-exercice (corrige)

Donnees : Prix = 24 EUR, BPA = 1,50 EUR, Dividende = 0,60 EUR.

1. PER = 24 / 1,50 = 16
2. Payout = 0,60 / 1,50 = 40 %
3. Rendement dividende = 0,60 / 24 = 2,5 %

Lecture : valorisation "moyenne", distribution raisonnable, rendement modeste. Pas de jackpot. Pas de drapeau rouge evident sur ces seuls chiffres.

## A toi

Choisis une action (sans l'acheter). Remplis PER, payout, rendement. Ajoute une phrase : "ce qui me rassure / ce qui m'inquiete".

:::retenir
PER + payout + historique de benefice > un seul ratio isole.
:::

:::attention
Un rendement dividende tres haut peut signaler un cours qui s'effondre, pas une aubaine.
:::

:::astuce
Ecris toujours V0 = D1/(r-g) avec tes hypotheses. Change r et g de +/-1 point : vois si ta conclusion tient.
:::
