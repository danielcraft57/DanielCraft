# Chapitre 16 - Atelier : lire une obligation

Atelier pratique. Obligation inventee : **Oblig VilleVerte 2029**. Tu calcules coupon, prix approx, YTM approx, choc de duration.

## Donnees

- Nominal F = 100
- Coupon annuel C = 3 (soit 3 %)
- Maturite restante n = 4 ans
- Prix P = 96
- Notation inventee : BBB
- Duration modifiee annoncee = 3,7

## Travail guide

1. Coupon annuel = 3 EUR pour 100 de nominal
2. Current yield = 3 / 96 = 3,125 %
3. YTM approx = [3 + (100 - 96) / 4] / [(100 + 96) / 2]
   = [3 + 1] / 98
   = 4 / 98
   ~ 4,08 %
4. Choc taux +1 % : variation ~ -3,7 % => prix estime ~ 96 x (1 - 0,037) = 92,45
5. Lecture credit : BBB = investment grade bas de fourchette ; spread vs Etat a surveiller

## Decision pedagogique

Sam : "YTM ~4 % avec duration 3,7 et BBB. Acceptable seulement en petite poche obligations diversifiee (ETF), pas en titre unique 20 % du patrimoine. Horizon > 4 ans ou acceptation de volatilite si revente avant."

Nora : "Ma poche B ne touche pas ca. Ma poche C obligations : via ETF IG duration < 5."

## A toi

Refais YTM approx et le choc +1 %. Puis ecris : "j'achete / je passe" avec une contrainte de % max.

:::retenir
Lire une obligation = coupon + prix + YTM + duration + credit.
:::

:::attention
Un YTM attractif peut cacher un credit fragile ou une duration trop longue pour toi.
:::

:::astuce
Calcule toujours le prix apres +1 % de taux avant d'augmenter la poche.
:::
