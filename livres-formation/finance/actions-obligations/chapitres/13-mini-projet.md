# Chapitre 13 - Mini-projet : portefeuille pedagogique

Tu vas construire un **portefeuille sur papier**. Pas de virement reel obligatoire. L'objectif : coller horizon, enveloppe, duration, et regles anti-panique. Chez DanielCraft, le mini-projet vaut plus qu'une dixieme video.

Disclaimer : fictif. Adapte a ta situation. Demande un avis competent si besoin.

## Situation inventee (au choix)

**Profil Nora** : salariee, poche B = 4 mois de charges OK, poche C = 12 000 EUR a investir progressivement, horizon 10+ ans, aversionite PEA.

**Profil Max** : revenus irreguliers, poche B incomplete (1,5 mois), veut comprendre avant d'acheter. Priorite : remplir B.

**Profil Sam** : deja un CTO fourre-tout, veut simplifier en 3 lignes max.

Choisis un profil (ou le tien). Reste coherent.

## Etapes (a ecrire)

1. **Poches** : montants cibles A / B / C. Si B < 3 mois, le projet C attend.
2. **Enveloppe** : PEA, CTO, ou les deux - avec pourquoi.
3. **Allocation papier** (exemple, pas une verite) :
   - C actions : ETF large eligible
   - C obligations (si horizon et estomac) : duration <= ton plafond
   - Cash de souplesse : % explicite
4. **Chiffres a calculer** :
   - Sur 10 000 EUR actions, choc -25 % = ? EUR
   - Sur 5 000 EUR obligations duration 6, choc taux +1 % ~ -6 % = ? EUR
5. **Versement** : montant automatique mensuel (meme 50 EUR) + date.
6. **Trois regles anti-panique** : ex. "pas de vente sur un tweet", "je relis le chapitre duration", "je ne double pas apres une baisse pour me venger".

## Grille de validation

Ton plan est OK si tu peux repondre oui a :
- Je sais ce que je detiens (indice / credit / duration)
- Je sais ou c'est range (PEA/CTO)
- Je sais quoi faire si -20 % sur actions
- Je n'ai pas besoin de cet argent l'an prochain

## Petite histoire

Nora remplit la grille un dimanche. Elle decouvre qu'elle voulait un ETF non eligible PEA "parce que le logo est beau". Elle change pour un equivalent eligible. Trente minutes. Gros ecart de clarte.

## A toi

Une page manuscrite ou un fichier. Titre : "Plan C - date". Relis-le dans 30 jours.
