# Chapitre 12 - Mini-projet : plan crypto fictif

Ce chapitre n'est pas un ordre d'achat. C'est un **plan sur papier** : plafonds, garde, horizon, et un choc simule. Chez DanielCraft, le mini-projet sert a freiner le FOMO avant qu'il ne signe a ta place. Tu peux tout faire avec un carnet et une calculatrice. Tu n'as besoin d'aucun compte exchange pour reussir l'exercice.

Disclaimer pedagogique : les chiffres en euros sont **inventes**. Les cryptos peuvent **tout perdre**. Ce plan ne remplace ni un conseiller agree, ni un fiscaliste. Si tu n'as pas de poche B (reserve), tu n'as pas non plus de permission emotionnelle pour une poche C speculative. Ecris-le clairement, meme si ca fait moins "web3".

Nora veut "enfin un cadre". Max a un loyer serre et refuse de jouer avec la reserve. Sam veut tester le geste wallet sans confondre curiosite et all-in. Trois temperaments. Un meme livrable : une page datee "Plan crypto" que tu peux relire dans trois mois sans rougir.

## Pourquoi un plan avant un compte

Sans % max, le prochain bull run decide pour toi. Sans lieu de garde ecrit, tu improvises le jour ou un DM "support" arrive. Sans choc -50 %, tu decouvriras ton estomac au pire moment. Le plan n'est pas une prediction de prix. C'est une permission limitee : "je peux perdre jusqu'a X euros sans casser ma vie".

Le mini-projet force aussi la separation des poches. Poche A = courant. Poche B = reserve. Poche C = risque plafonne. La crypto, dans ce livre, vit en C - ou nulle part. Si tu melanges B et C "parce que ca remonte toujours", tu n'as plus de plan : tu as une histoire.

## Etapes detaillees (a faire dans l'ordre)

**Etape 1 - Patrimoine d'ordre de grandeur.** Note un montant invente ou reel (arrondi). Exemple invente : 40 000 EUR de patrimoine net "vu large". Pas besoin d'exactitude comptable. Besoin d'un denominateur pour calculer un pourcentage.

**Etape 2 - % max crypto total.** Choisis un plafond, souvent entre 0 et 5 % pour un debutant prudent dans l'esprit DanielCraft. Exemple : 4 %. Calcul : 4 % de 40 000 = **1 600 EUR**. Ce plafond est le plafond de la poche C crypto, pas un objectif d'achat force. 0 % est une reponse valide.

**Etape 3 - Repartition fictive a l'interieur du plafond.** Decoupe les 1 600 EUR. Exemple pedagogique :
- 70 % BTC = 1 120 EUR
- 20 % ETH = 320 EUR
- 10 % stable "parking" = 160 EUR
- "Autres" (altcoins, NFT, DeFi exotique) = 0 EUR, ou un tout petit plafond ecrit a part si tu insistes

Pourquoi plafonner "autres" ? Parce que la surface d'erreur y explose : liquidite, contrat, narrative, phishing. Le plan n'interdit pas la curiosite. Il interdit de laisser la curiosite manger le plafond.

**Etape 4 - Lieu de garde.** Pour chaque ligne, ecris ou ca vit : CEX (contrepartie plateforme), wallet chaud (telephone / extension), froid (hardware / offline) plus tard si les montants le justifient. Exemple : stables et petit ticket sur CEX test ; BTC/ETH eventuellement self-custody apres atelier wallet. Le lieu de garde n'est pas un detail cosmetique : c'est le risque operationnel.

**Etape 5 - Choc -50 % sur la poche risque.** Les stables "parked" ne sont pas magiquement immunes (depeg possible), mais pour l'exercice pedagogique on simule surtout la partie volatile. Sur 1 120 + 320 = 1 440 EUR de BTC+ETH, un choc -50 % => perte environ **720 EUR**. La poche passe d'environ 1 600 EUR a environ 880 EUR si les 160 EUR de stable tiennent la parite. Dis a voix haute : "je perds 720 euros". Si la phrase te serre la gorge ou touche le loyer, baisse le % **maintenant**, pas apres.

**Etape 6 - Regles ecrites.** Trois minimums : pas de levier / futures pour ce plan ; seed jamais partagee ni tapee sur un site ; revue trimestrielle avec date. Ajoute ce que tu veux : pas de mint NFT urgent, pas d'augmentation de poche apres une video motivante, pas de moyenner a la baisse sans nouvelle limite ecrite.

## Exemple calcule (Nora vs Max)

Patrimoine invente 40 000 EUR. Nora accepte 4 % => 1 600 EUR. Repartition 70/20/10. Choc -50 % sur la partie risque ~ -720 EUR. Elle note "acceptable : oui, ca ne casse pas la poche B". Max, meme patrimoine sur le papier mais cashflow serre, calcule le meme -720 EUR et repond "non". Il baisse a 1 % => 400 EUR. Choc -50 % sur ~360 EUR de risque => ~ -180 EUR. Moins heroique. Plus tenable. Sam garde 0 % d'achat et fait seulement l'atelier wallet : le plan peut etre "comprendre sans exposer".

Recalcul rapide si Nora passe a 2 % : plafond 800 EUR ; 70/20/10 => 560 / 160 / 80 ; -50 % sur 720 EUR de risque => -360 EUR. Le plan n'est pas fige a vie. Il est fige jusqu'a la prochaine revue datee - pas jusqu'au prochain tweet.

## Petite histoire

Nora remplit la page un dimanche. Sam lui demande le choc a voix haute. Elle baisse de 4 % a 3 % sans drama. Max refuse d'ouvrir un compte "parce que le plan n'est pas fini" : il a raison. Le compte sans plan est une invitation a improviser. DanielCraft prefere une page ennuyeuse a une anecdote de bull run.

## Erreur classique

Ecrire un % max puis l'oublier au premier pump. Ou simuler -10 % seulement "parce que -50 % n'arrivera pas". Ou mettre la reserve d'urgence dans le meme panier "temporairement". Ou compter sur le levier pour "accelerer le plan". Le plan meurt quand tu le renegocies sous adrenaline.

## En vrai

Prends une feuille. Ecris les six etapes en six lignes. Calcule au moins un choc -50 % en euros. Ne cree aucun compte pour cet exercice.
