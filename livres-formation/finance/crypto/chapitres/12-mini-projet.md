# Chapitre 12 - Mini-projet : plan crypto fictif

Ce mini-projet se fait **sur papier** (ou tableur). Objectif : plafonds, garde, horizon - sans FOMO et sans depot. Chez DanielCraft, un plan ennuyeux bat une anecdote de gain. Si tu refuses d'ecrire les chiffres, tu n'es pas pret a signer une transaction.

Disclaimer : exercice pedagogique. Exemples inventes. Pas un conseil d'allocation.

## Etapes

1. Patrimoine invente ou reel (ordre de grandeur seulement).
2. % max crypto total (exemple : 0 a 5 %). Zero est une reponse valide.
3. Repartition fictive : BTC / ETH / stable / autres (autres plafonne fort, souvent a 0 pour debuter).
4. Lieu de garde : CEX / chaud / froid - et le montant max par lieu.
5. Choc -50 % : perte en euros = ? Dis-la a voix haute.
6. Regles : pas de levier, pas de seed partagee, revue trimestrielle, journal des operations.

Exemple invente :
- Max crypto 4 % de 40 000 = 1 600 EUR
- 70 % BTC, 20 % ETH, 10 % stable parking
- Sur la poche risque (BTC+ETH ~ 1 440 EUR), -50 % ~ -720 EUR
- Stable suppose "tenu" (en vrai, depeg possible : note le risque)
Acceptable pour Nora : oui, si -720 EUR = argent de jeu. Pour Max au loyer serre : non => il baisse le % a 1 % ou 0.

Sam ajoute une ligne "date de revue" et une ligne "je n'augmente pas la poche apres un pump sans recalculer -50 %". Max ajoute "montant max sur exchange = 300 EUR". Trois plans. Une meme idee : le papier decide avant l'emotion.

## Ce que ce n'est pas

Ce n'est pas un portefeuille "optimal". Ce n'est pas une prediction de bull run. Ce n'est pas une permission d'ignorer les poches A/B. Si ta poche B est vide, le % crypto recommande par ce livre est 0 jusqu'a ce que la reserve existe.

## Petite histoire

Nora remplit le plan en vingt minutes, le range, et n'achete rien pendant un mois. Elle revient, relit, ajuste le % de 4 a 2. Sam saute l'etape papier, achete "un peu", puis panique a -30 %. Il recommence le mini-projet apres coup. Plus douloureux. Plus pedagogique.

## Erreur classique

Ecrire 5 % puis passer a 20 % "parce que ca monte". Ou oublier les frais et le gas dans le plan. Ou mettre "autres / gems" a 40 % "pour booster".

## En vrai

Ouvre une page blanche. Titre : "Plan crypto - date". Remplis les six etapes sans telephone de trading ouvert.

## A toi

Une page "Plan crypto - date". Calcule le -50 %. Si le chiffre te fait mal au budget vie, baisse le % maintenant.
