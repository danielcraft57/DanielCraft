# Chapitre 12 - Mini-projet : plan crypto fictif

Plan **sur papier**. Objectif : plafonds, garde, horizon - sans FOMO.

## Etapes

1. Patrimoine invente ou reel (ordre de grandeur)
2. % max crypto total (ex. 0 a 5 %)
3. Repartition fictive : BTC / ETH / stable / autres (autres plafonne fort)
4. Lieu de garde : CEX / chaud / froid
5. Choc -50 % : perte en euros = ?
6. Regles : pas de levier, pas de seed partagee, revue trimestrielle

Exemple :
- Max crypto 4 % de 40 000 = 1 600 EUR
- 70 % BTC, 20 % ETH, 10 % stable parking
- -50 % sur la poche risque ~ -720 EUR (si stables stables...)
Acceptable pour Nora : oui. Pour Max loyer serre : non => % baisse.

## A toi

Une page "Plan crypto - date".

:::retenir
Plan = plafonds + garde + choc simule.
:::

:::attention
Sans % max, le prochain bull run decide pour toi.
:::

:::astuce
Si -50 % te fait mal au budget vie, baisse le % maintenant.
:::
