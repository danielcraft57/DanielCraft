# Chapitre 18 - Securite et phishing

Phishing = faux sites, faux apps, faux supports. Malware = drains de clipboard (adresse remplacee). Chez DanielCraft, la securite est un **rituel**, pas un antivirus miracle.

## Rituels

- Verifier les 4-6 premiers/derniers caracteres d'une adresse apres collage
- Small test transfer avant gros montant
- 2FA non SMS si possible (app / cle)
- Separater navigateur / machine pour gros montants si besoin

## Petite histoire

Nora copie une adresse. Le malware change le milieu. Elle verifie les caracteres. Sauvee. Max n'a pas verifie une fois. Lecon chere.

## A toi

Ajoute "verifier adresse" a ta checklist.

:::retenir
Petit transfert test + verification d'adresse.
:::

:::attention
Clipboard hijack existe. Regarde ce que tu as colle.
:::

:::astuce
2FA app > SMS quand c'est possible.
:::
