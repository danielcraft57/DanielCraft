# Chapitre 15 - Atelier : allocation crypto fictive

Capital pedagogique : **2 000 EUR** (argent "risque").

## Contraintes

- Pas de levier
- Max 3 lignes
- Stable <= 20 %
- Shitcoin / meme = 0 dans cet atelier

## Proposition corrigee (exemple)

| Ligne | % | EUR |
|---|---|---|
| BTC | 60 % | 1 200 |
| ETH | 25 % | 500 |
| Stable parking | 15 % | 300 |

Choc -50 % sur BTC+ETH (~1 700) => -850 EUR. Portefeuille ~ 1 150 + 300 stable = 1 450. Perte ~ -550 EUR (-27,5 %).

Nora valide si -550 EUR = "argent de jeu". Sinon baisse le capital.

## A toi

Fais ta grille. Calcule -50 %.

:::retenir
Allocation = plafonds + scenario de perte.
:::

:::attention
Ajouter une 4e ligne "gem" casse souvent la discipline.
:::

:::astuce
Si tu ne peux pas calculer -50 %, tu n'es pas pret.
:::
