# Chapitre 13 - Retenir l'essentiel

- Blockchain = carnet partage, pas gain garanti
- BTC/ETH = actifs risques ; plafonne le %
- Cles / seed = controle ; support ne demande jamais la seed
- Exchange = contrepartie ; teste les retraits
- Volatilite : -50 % => il faut +100 % pour revenir
- Stables = promesse de parite, pas livret
- DeFi / NFT = surface d'attaque large
- Taxes : journal ; regulation : verifie l'acteur
- Levier : souvent non pour ce livre
