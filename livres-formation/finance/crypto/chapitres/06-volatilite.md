# Chapitre 6 - Volatilite crypto

La **volatilite** crypto est souvent plus haute que celle des grands indices actions. -20 % en quelques jours n'est pas "impossible". Chez DanielCraft, on dimensionne la poche pour survivre au trou, pas pour gagner un argument Twitter.

Disclaimer : exemples inventes.

## Choc simple

Poche crypto = 3 000 EUR. Choc -40 % => 1 800 EUR. Perte = 1 200 EUR.  
Si ces 3 000 EUR etaient la poche B (reserve), le plan de vie casse. D'ou : crypto = poche C speculative plafonnee.

Drawdown approx :

Perte = Capital x (1 - facteur restant)

Apres -50 %, il faut +100 % pour revenir. L'asymetrie humilie les rattrapages heroiques.

## Vol realisee vs sentiment

Les indicateurs on-chain / MVRV / NUPL existent pour les curieux. Pour ce livre : si tu ne dors pas, la taille est trop grosse. Point.

## Petite histoire

Nora passe de 15 % a 3 % du patrimoine apres une nuit blanche. Elle n'a pas "predit le bottom". Elle a ajuste l'estomac.

## Erreur classique

Moyenner a la baisse sans limite ("je recharge jusqu'a zero").

## A toi

Ecris ton choc max acceptable (-30 % ? -50 % ?) et la taille de poche qui le respecte.

:::retenir
Volatilite haute => taille petite. Revenir de -50 % demande +100 %.
:::

:::attention
Levier + volatilite = liquidation avant ton "long terme".
:::

:::astuce
Simule -50 % sur ta poche avant d'acheter.
:::
