# Chapitre 11 - NFT : prudence

Un **NFT** est souvent un jeton unique pointant vers un media / droit. Art, billetterie, gadgets... Le marche a connu euphorie et hangover. Chez DanielCraft : curiosite OK, FOMO non.

Disclaimer : beaucoup de NFT valent près de zero. Droit legal != JPEG Twitter.

## Risques

Liquidite faible, royalties floues, metadata off-chain, wash trading, phishing de mint.

## Petite histoire

Max mint "parce que la communaute". Gas cher, floor collapse. Il garde le souvenir. Pas le capital.

## A toi

Budget NFT max = 0 sauf argent de jeu etiquete. Ecris le montant.

:::retenir
NFT = jeton + recit. Recit != liquidite.
:::

:::attention
Mint urgent + site inconnu = phishing frequent.
:::

:::astuce
Verifie le contrat / collection officielle avant de signer.
:::
