# Chapitre 14 - Atelier : configurer un wallet test

Atelier **sans fonds** (ou dust minime que tu acceptes de perdre). Le but n'est pas d'etre "on-chain". Le but est d'apprendre le geste de creation / restauration avant que l'argent arrive. Chez DanielCraft, on prefere un test ennuyeux a une premiere fois paniquee.

Disclaimer : verifie l'editeur de l'app. Pas de recommandation de marque. Pedagogy.

## Etapes

1. Installe un wallet reputable (extension ou mobile) - verifie l'editeur / store officiel.
2. Cree un wallet neuf.
3. Note la seed sur papier (test uniquement).
4. Verifie les mots dans l'ordre.
5. Lock / unlock plusieurs fois.
6. Option : restore sur un second appareil de test.
7. Efface le test ; ne reutilise **jamais** cette seed pour de vrais fonds.

Si une etape te demande de "valider" la seed sur un site web tiers, arrete. Tu es sorti du parcours legitime.

## Checklist anti-phishing

- URL / editeur corrects
- Pas de DM support
- Pas de site "valider seed"
- Pas de capture d'ecran de la seed
- Pas de cloud notes pour la seed

## Petite histoire

Max brule l'atelier en cinq minutes "parce que c'est simple", saute la restauration, et galere plus tard. Nora prend vingt minutes, restore, sourit, efface. Sam attend d'avoir un montant qui justifie un hardware avant d'en acheter un : l'atelier logiciel lui suffit pour commencer.

## Erreur classique

Reutiliser la seed de test pour de vrai. Photographier la seed "au cas ou". Installer l'app via un lien Discord.

## En vrai

Fais les etapes 1 a 7 aujourd'hui. Chronometre. Note ce qui t'a stresse.

## A toi

Coche : seed never online. Oui/non. Si non, corrige avant tout depot.

:::retenir
Le geste de restauration se pratique a froid, sans argent.
:::

:::attention
Une seed de test compromise n'est grave que si tu la reutilises pour de vrai.
:::

:::astuce
Hardware plus tard, quand les montants le justifient.
:::
