# Quiz final

Pas de piege. Relis une fois si besoin. L'idee : verifier que tu vois l'argent clairement, avec prudence, sans te prendre pour un gourou.

## Questions

1. La finance de base, dans ce livre, c'est surtout :
- A) Devenir trader en une semaine
- B) Comprendre flux, budget, dettes, tresorerie et decisions prudentes
- C) Copier les placements d'un influenceur

2. "Argent promis" (devis signe, facture envoyee) :
- A) Est deja du cash disponible
- B) N'est pas encore de l'argent disponible tant que ce n'est pas encaisse
- C) Remplace toujours un acompte

3. Un budget perso utile sert surtout a :
- A) Te punir sur chaque depense
- B) Voir si le mois tient et ou vont les euros
- C) Remplacer toute discussion de couple / coloc

4. Pour commencer a epargner, le plus solide est souvent :
- A) Attendre d'etre riche
- B) Un petit montant regulier, separe, avec un but
- C) Tout placer d'un coup dans un produit incompris

5. Avant de signer un credit, regarde surtout :
- A) Uniquement la mensualite la plus basse
- B) Cout total, duree, capacite a rembourser, pourquoi clair
- C) Le sourire du vendeur

6. Les interets d'un emprunt, en image simple :
- A) Un cadeau de la banque
- B) Une partie du prix du credit dans le temps
- C) Toujours nuls si on ne lit pas le contrat

7. Une bonne hygiene de compte bancaire inclut :
- A) Ignorer les releves
- B) Surveiller prelevements, frais, alertes, et separer une reserve
- C) Donner son code a un "conseiller" qui appelle

8. La tresorerie d'une petite activite, c'est surtout :
- A) Le chiffre d'affaires annonce sur les reseaux
- B) L'argent disponible pour payer maintenant, avec une prevision des flux
- C) Un sujet reserve aux grandes entreprises

9. Une marge saine suppose :
- A) De compter les couts (dont le temps) avant de fixer le prix
- B) De toujours aligner le prix du concurrent sans calculer
- C) De baisser des que quelqu'un fronce les sourcils

10. Un devis clair contient souvent :
- A) Uniquement un prix rond sans perimetre
- B) Perimetre, limites, prix, delai, validite (et acompte si besoin)
- C) Des promesses orales non ecrites

11. Face aux impots / cotisations (idee prudente) :
- A) On ignore jusqu'au jour J
- B) On provisionne, on note les echeances, on se renseigne via sources fiables / pro
- C) On copie un montage opaque trouve sur un forum

12. Un signal d'arnaque frequent :
- A) Une invitation a comparer tranquillement deux banques
- B) Gain rapide sans risque + pression + secret + demande de codes / cartes cadeaux
- C) Lire un releve le dimanche
