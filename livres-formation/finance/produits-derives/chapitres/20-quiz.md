# Quiz final

Douze questions pour verifier le socle **Finance - Produits derives**. Une seule bonne reponse par question. Relis un chapitre si besoin. Chez DanielCraft, le quiz ancre, pas le piege.

Ce livre est pedagogique. Reussir le quiz ne te qualifie pas pour trader leve en reel.
