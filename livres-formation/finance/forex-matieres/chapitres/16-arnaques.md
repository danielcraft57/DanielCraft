# Chapitre 16 - Arnaques forex et commodities

Le forex et les matieres attirent les scripts d'arnaque : robots "garanti", copy trading opaque, signal VIP, faux brokers, recuperation de pertes. Chez DanielCraft, le defaut est **non**.

## Red flags

- Rendement eleve garanti
- Urgence / places limitees
- Demande de codes / seed / remote access
- Broker impossible a verifier
- "Rembourse tes pertes" apres un premier depot

## Hygiene

Verifie l'entite legale, les alertes AMF, les conditions de retrait. Parle a quelqu'un hors ecran avant un virement.

## Petite histoire

Max recoit "expert petrole 10 % / semaine". Il cherche le nom sur le site AMF alertes. Signal. Il coupe.

## A toi

Ecris ta phrase de raccrochage.

:::retenir
Garanti + urgent + opaque = non.
:::

:::attention
Un faux gain sert a te faire deposer plus.
:::

:::astuce
Favoris : page alertes regulateur. Avant le cold call.
:::
