# Chapitre 14 - Atelier : une paire sur papier

Paire inventee : **EUR/USD**.

## Donnees

- Bid / Ask a l'entree : 1,0840 / 1,0842 (spread 2 pips)
- Tu "achètes" a 1,0842 (long), taille 0,10 lot (~1 USD/pip)
- Sortie : bid 1,0872
- Frais overnight ignores ici

## Travail

1. Pips bruts = 1,0872 - 1,0842 = 0,0030 = **30 pips**
2. P&L approx = 30 x 1 = **+30 USD**
3. En EUR (taux 1,08) ~ **+27,8 EUR**
4. Cout spread a l'entree ~ 2 pips deja "payes" dans le prix ask

## Decision

Nora : "interessant pour comprendre. Pas assez pour ouvrir un compte."
Max : "mon vrai risque est ma facture USD, pas ce trade."
