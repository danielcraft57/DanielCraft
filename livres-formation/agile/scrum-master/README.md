# Devenir Scrum Master

Livre DanielCraft pour **devenir Scrum Master** sur le terrain : servant leadership, facilitation, freins, focus, coaching - sans promesse de certification ni titre magique.

Public : facilitateurs en herbe, devs qui aident l'equipe, independants, petites structures du Grand Est. Ton pratique, Lea / Max / Sam. Pas un examen PSM - des gestes utiles des la semaine prochaine.
