# Chapitre 10 - Remote et hybride

**Remote** et **hybride** changent la facilitation : fatigue video, asymetrie salle/visio, messages perdus. Le Scrum Master adapte le cadre sans le vider. Chez DanielCraft, on vise equite de parole et clarte asynchrone - pas "tout le monde a la camera 8h par jour".

Lea prepare un board a jour avant la daily. Max parlait trop en salle, les remote disparaissaient ; Sam alterne la prise de parole et resume dans le chat. Review : demo partage ecran + enregistrement court si besoin. Retro : outils de votes simples, timebox stricte.

Regles d'hybride : un facilitateur attentif aux ecrans, pas deux conversations paralleles (salle vs chat). Le focus se protege aussi contre le Slack permanent.

:::retenir
Remote OK si board clair, parole equitable, decisions ecrites. La distance n'excuse pas le flou.
:::

## Ce que ce n'est pas

Ce n'est pas supprimer la daily "parce que remote". Ce n'est pas non plus multiplier les reunions pour compenser. Ce n'est pas magique : la culture reste le vrai sujet.

## Petite histoire

Equipe hybride. Lea a institue "decisions dans le channel sprint". Sam a coupe les reunions en double. Max a gagne du calme. La review live est restee sacree. DanielCraft recommande ce melange async/sync.

## Erreur classique

Laisser les presents en salle decider sans les remote. Ou daily video de 40 min. Autre piege : zero trace ecrite.

:::attention
Si les remote decouvrent les decisions apres coup, ton hybride est casse - change la facilitation avant le prochain sprint.
:::

:::astuce
En hybride, un "buddy remote" en salle relait le chat a voix haute. Simple, efficace.
:::

## En vrai

Audite une ceremonie remote cette semaine : equite, duree, trace. Une amelioration concrete.

## A toi

Ecris 5 regles remote/hybride d'equipe. Fais voter. Affiche-les. Chez DanielCraft, ces regles evitent dix frustrations silencieuses.
