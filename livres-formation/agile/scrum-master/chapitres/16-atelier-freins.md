# Chapitre 16 - Atelier : freins

Atelier pour cartographier et traiter des **freins**. Objectif : 3 freins visibles, 1 traite jusqu'a la prochaine action lancee.

:::retenir
Frein utile = enonce clair + impact + proprietaire + prochaine action.
:::

## Deroulement (35 a 45 min)

0-10 : brainstorm freins (silence ecrit). 10-20 : regrouper, voter top 3. 20-35 : pour le n1, impact / qui / action sous 48h / comment on saura que c'est leve. 35-45 : communiquer a l'equipe. Stop.

## Ce que ce n'est pas

Ce n'est pas une seance de plainte. Ce n'est pas traiter les 15 freins d'un coup.

## Petite histoire

Frein n1 : acces manquant. Sam a contacte le bon humain le jour meme. Max a pu avancer. Lea a raye le frein en daily. DanielCraft aime cette chaine courte.

## Erreur classique

Freins flous ("communication"). Sans proprietaire. Autre piege : atelier sans suivi.

:::attention
Un frein "communication" n'est pas actionnable - precise qui, quoi, quand.
:::

:::astuce
Formule : "Parce que X, on ne peut pas Y, donc on perd Z."
:::

## En vrai

Lance l'action du frein n1 avant ce soir.
