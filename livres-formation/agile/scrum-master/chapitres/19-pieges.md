# Chapitre 19 - Pieges

Les **pieges** du SM : chef deguise, sauveur, secretaire, policier de process, metriques toxiques, fuite des conflits, theatre agile, burn-out du service. Chez DanielCraft, on les nomme pour les eviter sans honte. Lea est tombee dans le sauvetage. Max dans le jargon. Sam dans le trop de reunions "pour aider".

Detecter un piege tot est une competence. En sortir demande souvent un experiment inverse : moins faire, plus enseigner ; moins parler, plus chronometrer ; moins controle, plus questions.

:::retenir
Piege frequent = prendre le pouvoir ou tout porter. Remede = rendre, faciliter, enseigner.
:::

## Ce que ce n'est pas

Ce n'est pas une liste pour juger les autres. Ce n'est pas "tu es mauvais".

## Petite histoire

Lea a tout debloque seule pendant un mois. Conge : chaos. Elle a compris le piege sauveur. Semaine suivante : pairer sur les freins. DanielCraft raconte ca sans fierte ni honte - juste apprentissage.

## Erreur classique

Ajouter du process pour masquer un piege relationnel. Ou nier le piege parce que "les intentions sont bonnes".

:::attention
Si l'equipe ne decide plus sans toi, tu es dans le piege - planifie ton inutilite progressive.
:::

## En vrai

Coche ton piege dominant cette semaine. Une action anti-piege de 7 jours.

## A toi

Ecris : "Mon piege n1 est ___ . Mon garde-fou est ___ ." Relis chaque lundi. Chez DanielCraft, ce garde-fou vaut une formation.
