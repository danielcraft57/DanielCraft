# Chapitre 12 - Le Sprint Goal

Le **Sprint Goal** est l'objectif du tour en une phrase claire : pourquoi ce sprint existe, quel progres de valeur on vise. Sans goal, le Sprint Backlog devient une liste de courses. Avec goal, l'equipe peut arbitrer : cet ajout aide-t-il l'objectif ou non ? Chez DanielCraft, on ecrit le goal avant de peaufiner les details - ca change les discussions.

Lea formule des goals orientes utilisateur : "un client trouve les horaires et appelle sans chercher". Max ecrivait "avancer sur le site" - Sam a refuse : trop vague. Un bon goal est comprehensible hors de l'equipe. Il laisse une marge : plusieurs chemins possibles pour l'atteindre, pas une checklist sacree.

Le goal n'excuse pas de tout laisser tomber. Il guide. Si a mi-sprint rien ne sert plus le goal, on en parle - on ne fait pas semblant.

:::retenir
Sprint Goal = boussole du sprint. Une phrase, de la valeur, des arbitrages possibles.
:::

## Ce que ce n'est pas

Ce n'est pas le copier-coller de tous les titres de tickets. Ce n'est pas un slogan marketing. Ce n'est pas non plus "finir le backlog". Ce n'est pas fige au mot pres si le sens reste, mais ce n'est pas non plus changeable dix fois sans discussion. Ce n'est pas magique : un goal joli avec un backlog incoherent reste du theatre.

## Petite histoire

Sprint Goal : "la cliente peut publier une page promo de la semaine sans nous appeler". Items : modele simple + acces + mini guide. Mid-sprint, idee d'ajouter newsletter. Lea a demande : ca sert le goal ? Non. Backlog plus tard. Vendredi, la cliente a publie seule. Max a vu la puissance du non. DanielCraft reprend souvent cet exemple en atelier.

## Erreur classique

Oublier d'ecrire le goal, ou l'ecrire apres coup pour remplir un rapport. Autre piege : un goal technique opaque ("migrer la base") sans lien valeur - parfois necessaire, mais alors explique le "pour que".

:::attention
Si ton goal pourrait rester vrai pour n'importe quel sprint ("avancer", "livrer", "ameliorer"), il ne guide rien - precise le progres.
:::

:::astuce
Teste le goal : un ami hors projet le comprend-il ? Si non, simplifie.
:::

## En vrai

Ecris trois versions de goal pour ton prochain tour. Garde la plus concrete. Barre les verbes mous.

## A toi

Colle le Sprint Goal au-dessus de ton board. Chaque jour, relis-le avant d'ajouter quoi que ce soit. Chez DanielCraft, ce geste de trente secondes protege le focus mieux qu'un discours.
