# Chapitre 17 - Atelier : clarifier les roles

Atelier pratique. Tu vas clarifier **PO / SM / Developers** sur un projet reel (ou simule), meme si les titres officiels n'existent pas. Objectif : savoir qui priorise, qui facilite, qui construit - et ou ca se chevauche. Lea fait cet atelier en trente minutes avec des petites structures. Max resiste puis admet que "c'est plus clair que notre Slack". Sam chronometre et interdit les phrases vagues sur les post-its.

Chez DanielCraft, materiel : feuille A3, trois colonnes, feutres. Seul ou a deux. Premiere passe sans laptop.

:::retenir
Roles utiles = prenoms + responsabilites visibles + zones de cumul assumees.
:::

## Deroulement (30 a 40 min)

Minute 0-5 : ecris le nom du projet et le prochain Sprint Goal (meme brouillon). Minute 5-15 : trois colonnes PO / SM / Developers - mets des prenoms et 3 verbes d'action par colonne. Minute 15-25 : entoure les cumuls (meme personne dans deux colonnes) et ecris une regle "quand je porte telle casquette, je ___". Minute 25-35 : montre a quelqu'un, note une objection. Minute 35-40 : ajuste. Stop.

## Ce que ce n'est pas

Ce n'est pas un organigramme RH. Ce n'est pas "inventer trois postes a embaucher demain". Ce n'est pas non plus figer les roles pour un an. Si tu passes une heure sur les titres anglais, tu as rate l'atelier.

## Petite histoire

Lea a mappe une micro-equipe : Max = Developer + un peu SM, Lea = PO, Sam = SM ponctuel le vendredi. Le cumul Max etait assume : "je ne priorise pas seul le mercredi". Ca a stoppe deux conflits. DanielCraft reprend ce format souvent.

## Erreur classique

Laisser la colonne PO vide "parce que le client decide parfois". Ou mettre tout le monde partout. Autre piege : atelier joli jamais montre a l'equipe.

:::attention
Si personne n'a la casquette priorites, ton atelier a revele le vrai frein - traite-le avant le sprint.
:::

:::astuce
Ecris chaque verbe comme une action observable ("ordonne le backlog le lundi"), pas "etre responsable".
:::

## En vrai

Prends une photo de ta feuille. Envoie-la a l'equipe. Une question : "ca vous parle ?" Note les reponses brutes.

## A toi

Fais l'atelier aujourd'hui. Garde la feuille pour l'atelier sprint. Chez DanielCraft, roles moches et clairs battent titres beaux et flous.
