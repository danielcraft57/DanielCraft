# Methodologie Scrum

Livre DanielCraft sur la **methodologie Scrum** : cadre simple pour avancer par sprints, avec roles, artefacts et rituels utiles - sans promesse de certification ni recopie d'un guide officiel.

Public : petites equipes, independants, commerces du Grand Est, gens qui veulent comprendre Scrum pour s'en servir vraiment. Ton pratique, personnages Lea / Max / Sam. Pas un examen PSM / PSPO - de la methode terrain.

## Contenu (21 chapitres)

1. C'est quoi Scrum (cadre)
2. L'equipe Scrum
3. Roles (PO, SM, Developers)
4. Artefacts (backlogs et increment)
5. Le Sprint
6. Sprint Planning
7. Daily Scrum
8. Sprint Review
9. Retrospective
10. Ready / Done
11. Estimation relative
12. Sprint Goal
13. Anti-patterns (Scrum en carton)
14. Mini-projet (simuler un sprint)
15. A retenir
16. Tendances
17. Atelier roles
18. Atelier sprint
19. Atelier board
20. Quiz
21. Bravo
