# Chapitre 15 - Atelier : script de decouverte et de close

Cet atelier construit tes phrases - sans en faire un robot. Tu repartiras avec une trame d'appel / rendez-vous : ouverture, qualification, decouverte, transition vers proposition, close. Chronometre : 60 a 90 minutes, plus 20 minutes de jeu de role.

## But

Ecrire un script souple (guide, pas texte a lire tel quel) et le tester a voix haute avec un partenaire.

## Materiel

Feuille ou doc. Chronometre. Un ami, collegue, ou dictaphone si tu es seul. Ta grille Need / Timing / Budget / Decideur. Ta phrase pivot de valeur.

## Etapes

1. Ecris l'ouverture en 3 lignes : qui tu es, pourquoi tu appelles / pourquoi tu es la, combien de temps tu proposes. Ton naturel. Exemple : "Bonjour, c'est Lea. Suite a votre message pour le site, je vous propose 20 minutes pour comprendre le besoin avant tout devis. C'est ok ?"

2. Ecris 6 a 8 questions de decouverte, groupees : situation, probleme, impact, desir, contraintes, passe, decideurs. Une question = une idee. Pas de double barre.

3. Ecris 2 reformulations types avec un trou a remplir. "Si je resume, le vrai sujet c'est ___ parce que ___. On est d'accord ?"

4. Ecris la transition. "Vu ce que vous me dites, je vois deux chemins possibles. Je vous les envoie par ecrit avec les prix. Avant ca : il reste un point important ?"

5. Ecris 3 closes (doux, alternatif, net) adaptes a ton offre. Choisis-en un principal.

6. Ecris 3 relances courtes (reception, valeur, fermeture) - tu les reutiliseras.

7. Jeu de role : 15 minutes. Le partenaire joue un client presse, puis un client vague, puis un client "je reflechis". Tu n'as pas le droit de lire le script mot a mot : tu as le droit de le regarder.

8. Debrief : qu'est-ce qui sonnait faux ? Trop long ? Trop vendeur ? Trop timide ? Reecris les phrases qui ont coince.

9. Mets le script final sur une page. Titre : "Guide entretien - [ton offre]". Garde-le a portee avant les RDV.

## Variante solo

Enregistre-toi. Ecoute. Note les "euh", les excuses sur le prix, les questions oubliees. Refais une prise. La honte diminue ; la clarte monte.

## Criteres de reussite

Tu poses plus de questions que tu ne pitches en premiere partie. Tu as une reformulation. Tu as ose un close avec une date. Ton partenaire peut dire ce que tu as compris de son besoin.

## Si ca bloque

Script trop long : coupe de moitie. Peur du close : commence par "qu'est-ce qu'il vous manque pour decider ?" qui est un close en forme de question. Client trop joueur : recentre sur un scenario realiste de ton metier.

## Mini-banque de questions (a piocher)

"Comment ca se passe aujourd'hui quand un client veut prendre rendez-vous ?"
"Qu'est-ce qui a change pour que vous cherchiez une solution maintenant ?"
"Si c'etait regle, quelle semaine type vous auriez ?"
"Qu'avez-vous deja essaye ?"
"Qui d'autre sera impacte ou doit etre d'accord ?"
"Vous aviez une zone de budget en tete, meme large ?"

Tu n'utiliseras pas tout a chaque fois. Tu auras de quoi relancer quand le silence tombe.

## Apres l'atelier

Utilise le guide sur le prochain vrai entretien. Annote ce qui a marche. Le script vivant evolue ; le script dans un tiroir meurt.
