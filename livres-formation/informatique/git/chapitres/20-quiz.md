## Ce que ce n'est pas

Ce n'est pas un examen universitaire. Ce n'est pas non plus "tu as rate donc tu es nul en Git". Une question ratee pointe un chapitre. Tu rouvres dix minutes. Tu retestes demain. Ce n'est pas une course. Dix-huit questions, du temps, des notes sur papier. Lea a rate les questions undo la premiere fois. Elle a rouvert le chapitre 15. Elle a reussi la semaine suivante. ## Questions

1. Git sert surtout a :
- A) Dessiner des maquettes
- B) Garder l'historique des versions
- C) Remplacer un antivirus

2. GitHub, c'est :
- A) Un hebergeur de depots Git (+ collab)
- B) Un langage
- C) Un fichier `.gitignore`

3. `git init` :
- A) Envoie sur internet
- B) Cree un depot local
- C) Supprime l'historique

4. Avant `commit`, on fait souvent :
- A) `git add`
- B) `git push`
- C) `git clone`

5. `git status` sert a :
- A) Voir l'etat du dossier / index
- B) Fusionner
- C) Creer une PR

6. Une branche permet de :
- A) Compresser les images
- B) Travailler en parallele sans casser main
- C) Effacer GitHub

7. `git merge` :
- A) Clone un depot
- B) Fusionne des historiques / branches
- C) Ignore les fichiers

8. Un conflit veut dire :
- A) Git a plante pour toujours
- B) Deux versions du meme endroit a arbitrer
- C) Le disque est plein

9. `.gitignore` sert a :
- A) Decoruer le README
- B) Exclure des fichiers du suivi
- C) Accelerer internet

10. `git push` :
- A) Envoie tes commits vers le remote
- B) Telecharge seulement
- C) Cree une branche locale

11. `git pull` :
- A) Supprime origin
- B) Recupere (et integre) les commits distants
- C) Remplace `commit`

12. Un bon message de commit :
- A) `update`
- B) `Corriger le lien casse du menu`
- C) `asdf`

13. `git stash` :
- A) Met des modifs de cote temporairement
- B) Pousse sur GitHub
- C) Cree un remote

14. Sur un commit deja partage en equipe, prefere :
- A) `reset --hard` silencieux
- B) `git revert`
- C) Effacer le depot

15. Une pull request, c'est :
- A) Demander a fusionner une branche (souvent via review)
- B) Un virus
- C) Un type de conflit

16. `git clone` :
- A) Copie un depot distant en local
- B) Efface main
- C) Remplace status

17. `git log --oneline` :
- A) Affiche l'historique compact
- B) Installe Git
- C) Ouvre GitHub

18. Si push est rejected car remote en avance :
- A) Ignorer
- B) `git pull` puis reparer eventuellement, puis push
- C) Formater le PC
