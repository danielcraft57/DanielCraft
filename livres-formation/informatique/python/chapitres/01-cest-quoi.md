# C'est quoi Python ?

## Le langage en une phrase

Python est un langage de programmation lisible, polyvalent et tres populaire. Il sert a creer des sites, des scripts, de l'IA, de l'automatisation et bien plus. Sa syntaxe claire le rend ideal pour debuter.

## Pourquoi apprendre Python ?

Python est le langage le plus enseigne dans le monde. Il est utilise par des geants comme Google, Netflix et Instagram. Les offres d'emploi mentionnant Python explosent chaque annee.

## A quoi ca ressemble ?

```python
nom = "Lea"
print(f"Salut {nom}, bienvenue en Python !")
```

Ce code affiche : `Salut Lea, bienvenue en Python !`

## Petite histoire

Guido van Rossum cree Python en 1991 aux Pays-Bas. Il choisit le nom en reference aux Monty Python, pas au serpent. Depuis, Python a conquis la data science, le web et l'embarque.
