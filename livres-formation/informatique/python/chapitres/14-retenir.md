# Ce qu'il faut retenir

## Les briques essentielles

Apres ces chapitres, tu maitrises les bases de Python :

| Concept | Resume |
|---------|--------|
| Variables | Noms qui pointent vers des valeurs |
| Types | `int`, `float`, `str`, `bool` |
| Conditions | `if / elif / else` |
| Boucles | `for`, `while`, `break`, `continue` |
| Fonctions | `def`, `return`, parametres |
| Listes | Collections ordonnees, mutables |
| Dictionnaires | Paires cle-valeur |
| Fichiers | `open()`, `with`, lire/ecrire |
| Erreurs | `try/except`, `raise` |

## La methode

1. Lis le chapitre.
2. Tape les exemples toi-meme (pas de copier-coller).
3. Modifie-les pour voir ce qui change.
4. Fais les ateliers.
5. Reviens quand tu bloques.

> **Astuce DanielCraft** - Apprendre a coder, c'est comme apprendre a nager : il faut se jeter a l'eau.
