# Chapitre 14 - Ce qu'il faut retenir (bases)

Tu as les bases. Ensuite : exceptions + classes, puis ateliers.

## En une minute

- `print` / `input` / f-strings
- Variables + `snake_case`
- Types : str, int, float, bool, None
- `if` / `elif` / `else`
- `for` / `while` / `break` / `continue`
- Fonctions + `return` (+ apercu `*args`)
- Listes (slices, comprehension), tuples, sets
- Dictionnaires + `.get`
- Fichiers texte + JSON
- `import` (math, random, json, datetime...)

## Habitudes

1. Indentation propre (4 espaces)
2. Noms clairs
3. Tester souvent
4. Lire les messages d'erreur
5. Petites fonctions
6. `with open(...)` pour les fichiers

## Erreurs classiques

- Oublier `:` apres `if` / `for` / `def`
- Mauvaise indentation
- Comparer un nombre avec un texte (`"4"` vs `4`)
- Fichier introuvable (mauvais dossier)
- Confondre `=` et `==`
- Confondre `print` et `return`

## Carte mentale

1. Donnees (variables, listes, dicos)
2. Decisions (`if`)
3. Repetitions (boucles)
4. Organisation (fonctions, modules)
5. Memoire (fichiers / JSON)
