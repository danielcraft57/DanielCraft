# Ce qu'il faut retenir

## Les briques essentielles

| Concept | Resume |
|---------|--------|
| Variables | `val` immutable, `var` mutable |
| Types | `Int`, `Double`, `String`, `Boolean`, nullable `?` |
| Conditions | `if` expression, `when` puissant |
| Boucles | `for (x in range)`, `forEach` |
| Fonctions | `fun`, `= expression`, lambdas |
| Null safety | `?.`, `?:`, eviter `!!` |
| Classes | Constructeur primaire, `data class` |
| Collections | `listOf`, `filter`, `map` |
| Erreurs | `Result`, `runCatching`, `require` |

## La methode

1. Lis le chapitre.
2. Tape les exemples dans IntelliJ.
3. Fais compiler (le compilateur enseigne).
4. Fais les ateliers.
5. Reviens quand tu bloques.

> **Astuce DanielCraft** - Kotlin est concis mais exigeant. Chaque ligne compte.

## Ce qui vient apres

- Coroutines (async/await natif).
- Jetpack Compose (UI Android declarative).
- Spring Boot avec Kotlin.
- Multiplatform (KMP).

## A retenir

- Kotlin = concision + securite + interop Java.
- `val`, `data class`, `when`, null safety sont les piliers.
