# Apres les bases : Java intermediaire

Tu connais variables, methodes, classes. Le niveau **intermediaire**, c'est **structures utiles** et **API moderne** : collections, generics, streams, Optional, fichiers.

- List, Set, Map et generics.
- Interfaces, heritage, polymorphism.
- Streams, Optional, fichiers.
- Records, enums, mini-projet.
