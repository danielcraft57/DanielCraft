# Atelier : variables

## Exercice 1 : carte d'identite

```swift
let prenom = "Sam"
let age = 22
print("Je suis \(prenom), \(age) ans.")
```

## Exercice 2 : optional

```swift
var pseudo: String? = nil
pseudo = "DevNora"
let affichage = pseudo ?? "Anonyme"
print(affichage)
```

## Defi : temperature

```swift
let celsius = 37.0
let fahrenheit = celsius * 9 / 5 + 32
print("\(celsius)°C = \(fahrenheit)°F")
```
