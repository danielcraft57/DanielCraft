# Premier programme

## Hello World

```swift
print("Bonjour le monde !")
```

Dans un projet App, le point d'entree est `@main` sur une struct `App`.

## Affichage formate

```swift
let nom = "Sam"
let age = 28
print("Je suis \(nom), \(age) ans.")
```

## Les commentaires

```swift
// Commentaire sur une ligne
```

## Petite histoire

Nora ouvre un Playground, ecrit trois lignes, execute. Le resultat s'affiche dans le panneau de droite.

## A retenir

- `print()` pour afficher.
- Interpolation avec `\(variable)`.
- Playground pour tester rapidement.
