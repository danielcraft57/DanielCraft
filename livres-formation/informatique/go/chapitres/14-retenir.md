# Ce qu'il faut retenir

## Les briques essentielles

| Concept | Resume |
|---------|--------|
| Variables | `:=` raccourci, types stricts |
| Types | `int`, `float64`, `string`, `bool` |
| Conditions | `if` sans parentheses, `switch` sans break |
| Boucles | `for` uniquement, `range` pour parcourir |
| Fonctions | Retours multiples, `(valeur, erreur)` |
| Slices | Liste flexible, `append` |
| Maps | Cle-valeur, `val, ok := m[k]` |
| Structs | Donnees + methodes, composition |
| Interfaces | Implicites, contrat de methodes |
| Erreurs | Valeurs, `if err != nil`, `defer` |

## La methode

1. Lis le chapitre.
2. Tape les exemples.
3. Modifie pour voir.
4. Fais les ateliers.
5. Reviens quand tu bloques.
