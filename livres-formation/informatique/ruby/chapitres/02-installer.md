# Installer Ruby

## Windows

1. Telecharge **Ruby+Devkit** sur rubyinstaller.org.
2. Lance l'installeur et coche "Add to PATH".
3. Verifie : `ruby --version`.

## Mac / Linux

```bash
# Mac
brew install ruby

# Linux
sudo apt install ruby-full
```

## Editeur

VS Code + extension Ruby, ou RubyMine (JetBrains).

> **Astuce DanielCraft** - `gem` est le gestionnaire de paquets Ruby (comme npm ou pip).

## A retenir

- `ruby --version` pour verifier.
- `gem install nom_gem` pour les bibliotheques.
