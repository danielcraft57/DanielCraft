# C'est quoi Ruby ?

## Le langage en une phrase

Ruby est un langage oriente objet, concu pour etre agreable a ecrire et a lire. Matz (Yukihiro Matsumoto) le cree en 1995 avec la devise : rendre les programmeurs heureux.

## Pourquoi apprendre Ruby ?

Ruby alimente Ruby on Rails, l'un des frameworks web les plus influents. Il reste populaire pour le prototypage rapide, les scripts et le backend web.

> **Astuce DanielCraft** - Ruby te apprend a ecrire du code elegant. Meme si tu codes ailleurs, cette elegance reste.

```ruby
nom = "Lea"
puts "Salut #{nom}, bienvenue en Ruby !"
```

## A retenir

- Ruby = elegance + productivite.
- Tout est objet.
- Ideal pour le web (Rails) et les scripts.
