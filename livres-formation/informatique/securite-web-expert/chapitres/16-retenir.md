# Ce qu'il faut retenir

## Carte expert

- **Menaces** : STRIDE, zero trust, SSRF, uploads.
- **Identite** : OAuth/OIDC, rotation secrets.
- **Ops** : WAF, CI/CD, conteneurs, incident response.
- **Chain** : supply chain, SBOM, audits.

## Mindset

- Defense in depth + gouvernance.
- Mesurer, alerter, ameliorer (post-mortem).

## A retenir

- Expert = securite durable, pas un patch unique.
