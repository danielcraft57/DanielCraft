# Apres l'intermediaire : vision expert

Tu maitrises deja XSS, CSRF, auth, headers, CSP. Le niveau **expert**, c'est penser **architecture**, **processus** et **resilience** : menacer modeler, repondre aux incidents, securiser la chaine logicielle.

> **Astuce DanielCraft** - Expert = defense en profondeur + gouvernance. Toujours sans hacking offensif.

## Ce que tu vas apprendre

- Threat modeling et zero trust.
- OAuth/OIDC, API avancee, SSRF, uploads.
- Supply chain, CI/CD, conteneurs.
- Reponse a incident et rotation des secrets.

## A retenir

- Expert = securite dans le temps, pas seulement dans le code.
- Defense only, toujours.
