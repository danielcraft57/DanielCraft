# Apres les bases : aller plus loin

Tu connais deja les habitudes : mots de passe, HTTPS, phishing, mises a jour. Le niveau intermediaire, c'est **durcir** une application web : comprendre les failles courantes et les **freiner** cote defense.

> **Astuce DanielCraft** - On reste en mode defense. Pas d'exploitation, pas de hacking offensif.

## Ce que tu vas apprendre

- OWASP Top 10 (vue defense).
- XSS, CSRF, injections SQL.
- Auth, JWT, sessions.
- Headers, CSP, CORS, rate limiting.

## A retenir

- Intermediaire = appliquer des contre-mesures concretes.
- Defense only, toujours.
