# Chapitre 18 - Erreurs classiques

Les accidents debutants se ressemblent. Chez DanielCraft, on les nomme pour les **eviter**, pas pour juger. Lea tient cette liste pres du bureau. Max s'y reconnait sans dramatique. Sam en fait un oral de cinq minutes en fin de module.

:::retenir
Reconnaitre le piege. Appliquer le frein. Revenir a la carte.
:::

## Catalogue utile

1. **MDP reutilises** - frein : gestionnaire + uniques.  
2. **Maj ignorees** - frein : calendrier + backup avant.  
3. **Backup jamais testee** - frein : restore mensuelle.  
4. **Admin pour tout le monde** - frein : roles.  
5. **Confiance aveugle au cadenas** - frein : verifier le domaine.  
6. **Clic sur urgence** - frein : URL tapee / favori.  
7. **Validation JS seule** - frein : serveur.  
8. **Comptes test en prod** - frein : supprimer.  
9. **Secrets dans le repo** - frein : coffre / variables d'env.  
10. **"Je suis trop petit"** - frein : bots ne lisent pas ton CA.  

:::attention
Corriger une erreur ne demande pas d'apprendre a attaquer.
:::

## Petite histoire

Max a coche huit pieges sur dix "deja faits une fois". Lea a dit : "parfait, tu sais ou regarder". Sam a transforme la honte en plan. Chez DanielCraft, lucidite > perfection.

## Erreur classique (meta)

Collectionner les listes sans rien changer. Choisis-en deux cette semaine.

:::astuce
Affiche les trois pieges qui te concernent. Barre-les quand c'est corrige.
:::

## En vrai

Note ton top 3 personnel. Lie chaque item a un chapitre.

## Comment utiliser ce catalogue

Ne cherche pas a tout corriger en une nuit. Choisis deux lignes. Planifie. Reviens. Chez DanielCraft, la liste est un radar, pas une culpabilisation. Si tu formes une equipe, transforme trois erreurs en atelier de quinze minutes : signal, frein, case checklist.
