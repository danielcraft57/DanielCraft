# Chapitre 12 - Lire les erreurs

Le compilateur et la JVM parlent. Lis le **fichier**, la **ligne**, le **message**. Chez DanielCraft, Max respire avant de tout reecrire. Lea corrige une typo. Sam enseigne : "l'erreur est un GPS, pas une insulte."

Exceptions frequentes debutant : `NullPointerException`, index hors tableau, type incompatible.

:::retenir
Message + ligne + dernier changement = methode de debug.
:::

## A toi

Casse volontairement un programme et note les 3 infos de l'erreur.
