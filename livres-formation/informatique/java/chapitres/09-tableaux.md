# Chapitre 9 - Tableaux

```java
int[] notes = {12, 15, 9};
System.out.println(notes[0]);
System.out.println(notes.length);
```

Index commence a **0**. Boucle `for` pour parcourir. Chez DanielCraft, Max deborde (`notes[3]`) : exception. Lea utilise `.length`.

:::retenir
Tableau = cases numerotees a partir de 0.
:::
