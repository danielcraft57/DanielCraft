# Chapitre 1 - C'est quoi Java ?

**Java** est un langage pour ecrire des programmes qui tournent sur beaucoup de machines grace a la **JVM** (machine virtuelle). Tu ecris du `.java`, tu compiles en bytecode, la JVM execute. Chez DanielCraft, on commence simple : variables, conditions, methodes, puis objets. Lea veut comprendre avant Spring. Max a peur du jargon. Sam dit : "Java, c'est d'abord de la clarte."

:::retenir
Java = code source + compilation + execution via la JVM. Toi, tu restes le pilote.
:::

## Ce que ce n'est pas

Ce n'est pas JavaScript. Ce n'est pas obligatoire d'apprendre Android le jour 1. Ce n'est pas "que des objets" avant de savoir compter. Ce n'est pas magie : une erreur de type se lit et se corrige.
