# Chapitre 13 - Mini-projet

Programme console : **liste de taches** ou **compteur de points**.

1. Classe ou tableaux pour stocker
2. Menu texte (ajouter / afficher / quitter)
3. Boucle tant que pas quitter
4. Au moins une methode separee
5. Gerer une saisie invalide simplement

Lea fait le menu. Max gere le tableau. Sam teste les cas limites.

:::retenir
Petit programme complet > dix bouts isoles.
:::
