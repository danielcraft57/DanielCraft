# Chapitre 4 - Variables

Une **variable** range une valeur sous un nom. En Java, tu declares le type.

```java
int age = 20;
String prenom = "Lea";
```

:::retenir
Type + nom + valeur. La boite a une forme.
:::

## A toi

Declare `prix` (double) et `enStock` (boolean), affiche-les.

:::attention
Utiliser une variable avant de l'initialiser : souvent erreur.
:::
