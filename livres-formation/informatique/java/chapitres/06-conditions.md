# Chapitre 6 - Conditions

```java
if (age >= 18) {
  System.out.println("Majeur");
} else {
  System.out.println("Mineur");
}
```

`&&`, `||`, `!` combinent. Chez DanielCraft, Lea ecrit la condition en francais d'abord.

:::retenir
if / else = choisir un chemin selon une condition.
:::
