# Chapitre 2 - Installer et lancer (idee)

Tu as besoin d'un **JDK** (outils pour compiler et lancer). Puis un editeur (VS Code, IntelliJ Community...). Chez DanielCraft : verifier `java -version` et `javac -version`. Lea cree `Bonjour.java`. Max compile, puis execute.

Le cycle : ecrire -> `javac` -> `java NomDeLaClasse`. Les IDE font souvent ca en un bouton : comprends le geste quand meme.

:::retenir
JDK + fichier .java + compile + lance.
:::

## A toi

Note ta version Java affichee par `java -version`.

:::attention
Class public et nom de fichier doivent matcher (souvent).
:::
