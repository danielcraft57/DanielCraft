# Chapitre 3 - Premier programme

```java
public class Bonjour {
  public static void main(String[] args) {
    System.out.println("Bonjour");
  }
}
```

`main` est le **point d'entree**. `println` affiche une ligne. Chez DanielCraft, Lea change le texte, recompile, relance. Max oublie les accolades : l'erreur le ramene.

:::retenir
Classe + main + println = premier contact.
