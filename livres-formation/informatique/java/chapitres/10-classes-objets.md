# Chapitre 10 - Classes et objets

Une **classe** est un plan. Un **objet** est un exemplaire.

```java
public class Client {
  String prenom;
  int points;
}
```

Chez DanielCraft, Lea modelise un `Produit` (nom, prix). Max confond encore classe et fichier. Sam dit : "le plan / la chose".

:::retenir
Classe = plan. Objet = instance du plan.
:::
