# Chapitre 15 - Atelier : SELECT

Atelier lecture seule. Table inventee `produits(id, nom, prix, stock)`.

## Etapes

1. Ecris `SELECT * FROM produits;` (esprit)
2. Selectionne seulement `nom, prix`
3. Alias : `prix AS prix_eur`
4. Verifie mentalement 3 lignes

Chez DanielCraft, l'atelier SELECT apprend a ne pas tout afficher "parce que c'est plus simple". Lea choisit les colonnes utiles. Max commence toujours par `*` puis resserre.
