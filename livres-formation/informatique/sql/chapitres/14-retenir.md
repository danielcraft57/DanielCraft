# Chapitre 14 - Retenir l'essentiel

SQL, c'est poser une question claire a des tables. Tu choisis des colonnes (`SELECT`), une table (`FROM`), tu filtres (`WHERE`), tu tries (`ORDER BY`), tu limites (`LIMIT`). Tu geres l'absence (`NULL`). Tu resumes (`COUNT`, `SUM`, `GROUP BY`). Tu croises (`JOIN`). Tu modifies avec prudence (`INSERT`, `UPDATE`, `DELETE` + `WHERE`). Chez DanielCraft : petit, clair, verifie.

Lea retient : table = grille. Max retient : WHERE avant DELETE. Sam retient : JOIN sur une cle.

## Carte courte

- SELECT / FROM / WHERE / ORDER / LIMIT
- NULL n'est pas 0
- GROUP BY avec agregats
- INNER vs LEFT JOIN
- Cles primaire / etrangere
- Toujours verifier un echantillon

## A toi

Recopie ta phrase perso en une ligne.

:::retenir
Question claire + cle claire + echantillon verifie.
:::
