# Chapitre 16 - Atelier : filtrer avec WHERE

Table inventee `commandes(id, client_id, montant, ville_livraison)`.

## Missions

1. Montants > 50
2. Ville = 'Lyon'
3. Combine : Lyon ET montant >= 30
4. Liste triee par montant desc, 5 lignes

Max ecrit d'abord le filtre en francais ("commandes de Lyon pas trop petites") puis le traduit en SQL. Sam teste chaque condition separement.

## A toi

Ecris les quatre requetes. Entoure le WHERE d'un trait sur papier.

:::retenir
WHERE garde les lignes utiles. Une condition claire bat trois floues.
:::

:::attention
Oublier les guillemets sur un texte = erreur ou surprise.
:::

:::astuce
Traduis la phrase metier avant le SQL.
:::
