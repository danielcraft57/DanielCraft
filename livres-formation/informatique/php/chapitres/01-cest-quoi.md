# C'est quoi PHP ?

## Le langage en une phrase

PHP est un langage de programmation cote serveur, cree en 1995 par Rasmus Lerdorf. Il genere des pages web dynamiques : formulaires, bases de donnees, sessions, API. Environ 77% des sites web utilisent PHP (dont WordPress, Wikipedia, Facebook a ses debuts).

## Pourquoi apprendre PHP ?

PHP reste le langage serveur le plus deploye au monde. WordPress (43% du web), Laravel, Symfony : l'ecosysteme est immense. Les offres d'emploi PHP sont nombreuses, surtout en agence web et e-commerce.

> **Astuce DanielCraft** - PHP est ideal pour commencer le backend. Tu vois le resultat directement dans le navigateur.

Nora installe PHP et XAMPP un dimanche matin. Elle cree `index.php`, ecrit `<?php echo "Bonjour"; ?>` et voit le texte dans son navigateur.

## A quoi ca ressemble ?

```php
<?php
$nom = "Lea";
echo "Salut $nom, bienvenue en PHP !";
```

## Petite histoire

Rasmus Lerdorf cree PHP pour gerer sa page personnelle (Personal Home Page). Le langage evolue : PHP 5 apporte l'objet, PHP 7 la performance, PHP 8 les types stricts et les attributs.

## En vrai

Sam cree un formulaire de contact avec PHP. Max developpe une boutique en ligne avec Laravel. Nora gere un blog WordPress et modifie les themes en PHP.

> **Piege** - PHP a une reputation de langage "ancien". En realite, PHP 8+ est moderne, type et performant.

## A retenir

- PHP est cote serveur, genere du HTML dynamique.
- 77% du web tourne sur PHP.
- PHP 8+ est moderne et performant.
