# Ce qu'il faut retenir

## Les briques essentielles

| Concept | Resume |
|---------|--------|
| Variables | `$nom`, typage dynamique |
| Types | `int`, `float`, `string`, `bool`, `array` |
| Conditions | `if/elseif/else`, `match`, `??` |
| Boucles | `for`, `foreach`, `while` |
| Fonctions | Types dans signatures (PHP 8+), `fn()` |
| Tableaux | Indexes et associatifs, `foreach` |
| Classes | `__construct`, visibilite, heritage |
| Formulaires | `$_GET`, `$_POST`, validation |
| Erreurs | `try/catch`, `throw` |

## La methode
