# Ce qu'il faut retenir

## Carte expert SQL

- **Exprimer** : fenetres, CTE, recursive.
- **Mesurer** : EXPLAIN, index cibles.
- **Proteger** : contraintes, transactions, isolation.
- **Scaler** : partitions, vues materialisees (quand utile).

## Mindset

- Clarte > ruse.
- Preuve (plan) > opinion.

## A retenir

- Expert SQL = architecte de questions fiables.
