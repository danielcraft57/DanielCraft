# Chapitre 10 - Index (idee)

Un **index** aide la base a retrouver des lignes plus vite (comme un index de livre). Chez DanielCraft : idee seulement. Trop d'index ralentit les ecritures. Lea indexe `commandes.client_id` si les jointures sont frequentes. Max n'indexe pas "au feeling" chaque colonne.

:::retenir
Index = accelerer certaines lectures. Pas une obligation partout.
:::
