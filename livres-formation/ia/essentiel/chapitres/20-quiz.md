# Quiz final

Pas de piege. Relis une fois si besoin. L'idee : verifier que tu peux utiliser l'IA avec methode, sans naivete ni panique.

## Questions

1. Une bonne definition debutant d'un LLM, c'est surtout :
- A) Un robot conscient qui connait la verite
- B) Un modele qui manipule le langage en produisant des suites plausibles, pas toujours vraies
- C) Un moteur de recherche officiel de l'Etat

2. Dans un prompt utile, on trouve souvent :
- A) Seulement "fais au mieux"
- B) Role, tache, public, contraintes, format (et des faits fournis si besoin)
- C) Uniquement des emojis pour "donner le ton"

3. Une hallucination, c'est :
- A) Quand ton ecran scintille
- B) Quand le modele invente des faits / sources avec assurance
- C) Quand l'outil refuse de repondre

4. Pour reduire les inventions, le geste le plus utile est :
- A) Demander "des sources" sans les ouvrir
- B) Fournir le materiel, forcer "inconnu si manque", et verifier ailleurs
- C) Regenerer vingt fois jusqu'a ce que ca sonne joli

5. Un usage quotidien solide pour commencer :
- A) Refondre toute sa boite en une nuit
- B) Ebaucher mails / resumes / plans sur des taches basses risque, avec relecture
- C) Laisser un agent envoyer tous les mails seul

6. Le multimodal leger sert surtout a :
- A) Remplacer toute photo reelle de ton travail
- B) Dicter, transcrire, decrire une image, generer des visuels non critiques avec verification
- C) Cloner la voix d'un client sans demander

7. Un agent, en idee simple, c'est :
- A) Un chat qui repond une fois
- B) Un systeme qui enchaine des actions vers un but, a cadrer avec interdits et validations
- C) Un antivirus

8. Face au RGPD / ethique, le reflexe de base est :
- A) Coller toutes les fiches clients pour "personnaliser"
- B) Minimiser / anonymiser, choisir des canaux adaptes, respecter les personnes
- C) Dire que "c'est anonyme" des qu'on enleve le prenom dans un petit village

9. Dans le travail, l'IA amplifie surtout :
- A) Celui qui sait juger et briefer
- B) Celui qui colle sans lire
- C) Uniquement les metiers "tech"

10. Pour choisir un outil, le mieux est :
- A) Suivre chaque hype la semaine de sa sortie
- B) Tester sur tes prompts / contraintes donnees / budget avec un protocole court
- C) Prendre trois abonnements annuels tout de suite

11. Une bonne pratique securite debutant :
- A) Partager son compte pro et coller les cles API dans le chat
- B) 2FA, minimiser les collages sensibles, pas d'agent avec envoi autonome
- C) Faire confiance a toute facture bien redigee

12. La phrase la plus saine avant d'envoyer un texte IA :
- A) "C'est fluide, donc c'est bon"
- B) "Est-ce que je signe les faits, le ton et les promesses ?"
- C) "Personne ne verifiera"

## Corriges

1-B, 2-B, 3-B, 4-B, 5-B, 6-B, 7-B, 8-B, 9-A, 10-B, 11-B, 12-B.

Si tu as 9/12 ou plus : tu es pret a pratiquer proprement au quotidien. Sinon, relis les chapitres lies (LLM, prompts, hallucinations, quotidien, multimodal, agents, ethique, metiers, choisir, securite, bonnes pratiques), sans dramatiser. Puis refais le quiz dans une semaine apres un vrai usage.
