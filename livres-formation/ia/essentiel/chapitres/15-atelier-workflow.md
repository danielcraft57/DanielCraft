# Chapitre 15 - Atelier : un workflow IA de A a Z

Cet atelier colle plusieurs gestes : brief, generation, (option) multimodal leger, verification, livraison. Tu construis un mini-pipeline personnel que tu pourras recreer la semaine prochaine. Chronometre : 90 a 120 minutes.

## But

Definir et executer un workflow en 5 a 7 etapes pour un livrable concret, avec une case "humain valide" avant toute diffusion.

## Materiel

Outil chat. Optionnel : telephone pour dictée, une photo non sensible. Doc "Workflow [nom]". Tes faits non negociables sur une feuille a part (source de verite).

## Etapes

1. Choisis un livrable unique. Exemples : proposition Lea 1 page ; devis+mail Max ; seance Sam 45 min ; ta FAQ 8 questions.

2. Dessine le flux sur papier : Entree (notes/photo/voix) -> Nettoyage / anonymisation -> Prompt plan -> Generation blocs -> Verif faits -> Polish ton -> Sortie. Barre ce qui est cosmetique.

3. Ecris pour chaque etape : outil utilise, duree max, critere "ok pour passer a la suite".

4. Prepare l'entree reelle (15 min). Anonymise. Separe faits certifiés et zones floues.

5. Execute le flux sans sauter la verif. Chronometre chaque etape. Si une etape depasse sa duree max, coupe le scope, ne "juste encore une regeneration".

6. Produis le livrable final dans un fichier propre (pas le chat).

7. Ecris le mode d'emploi du workflow en 10 lignes pour "toi dans 15 jours fatigue".

8. Identifie un goulot : ou tu as perdu du temps. Propose une seule amelioration (meilleur prompt, checklist, modele de doc).

9. Option agent-mental : ecris quelle etape pourrait etre un jour automatisee, et pourquoi pas encore (risque).

## Variante a deux

L'un execute. L'autre joue le controleur qualite : "montre la source de ce chiffre", "ce ton sonne IA", "donnee sensible ?". Inversez au prochain atelier.

## Criteres de reussite

Schema du workflow lisible. Livrable final hors du chat. Au moins une correction factuelle documentee. Mode d'emploi 10 lignes. Temps total note. Tu referais le meme flux la semaine prochaine sans reinventer.

## Si ca bloque

Trop ambitieux : reduis a un mail + une checklist. Pas de multimodal : saute. Modele qui divague : recommence un fil avec le plan valide seulement. Honte du rendu : le but est le process ; le rendu "assez bon" suffit ici.

## Exemple de sortie attendue

Workflow "Proposition artisan - Lea"
1. Notes call anonymisees (10 min)
2. Plan IA + validation humaine (15)
3. Generation 4 sections (25)
4. Verif prix/delai/perimetre (15)
5. Polish + limites explicites (15)
6. Export PDF/doc (10)
Amelioration : modele de doc avec titres fixes.

Si tu as ca + le fichier final, l'atelier a marche.

## Apres l'atelier

Recopie le workflow dans ta banque prompts / ops. Rejoue-le une fois sur un autre sujet proche sous 7 jours. Un workflow non rejoue n'existe pas.
